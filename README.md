# 🌾 FeedMixer ERP v3.0

نظام ERP كامل لإدارة **خلاطة الأعلاف** بلغة Python 3.10+ مع واجهة **Tkinter/ttk عربية (RTL)** وقاعدة بيانات **SQLite3**.

## 🧮 القواعد المحاسبية المعتمدة

1. **طنان الفوترة:** `int((kg + 249) / 500) * 0.5` (كل 500 كغ = 0.5 طن)
2. **سعر كيلو المادة:** `ton → (base+handling+loss)/1000` ، `kg → base+handling+loss` ، `fixed → base`
3. **تكلفة العلف:** `Σ (كمية_كغ × سعر_كغ)`
4. **أجور العمال:** `أنصاف_الأطنان × labor_fee_per_ton`
5. **الإجمالي:** `علف + كهرباء + عمال + نقل_المزرعة`
6. **الصافي:** الإجمالي (إلا لو عُدّل يدوياً — `net_cost_manually_edited`)
7. **المستحق على مزرعة:** `Σ الفواتير غير المحذوفة − Σ المدفوعات`

## 🔐 الأمان

- كلمات المرور: `sha256(salt + password)` مع salt عشوائي لكل مستخدم ومقارنة ثابتة الزمن (`hmac.compare_digest`).
- مصفوفة صلاحيات حسب الدور في `core/permissions.py` تطبَّق على الواجهة والعمليات.
- سجل تدقيق كامل في جدول `audit_log`.
- حماية: منع حذف آخر admin نشط، ومنع حذف مادة مستخدمة.

## 💾 النسخ الاحتياطي

من تبويب **إعدادات**: إنشاء نسخة احتياطية (timestamped) في `backups/`، استعادة نسخة، وفحص سلامة قاعدة البيانات (`PRAGMA integrity_check`).
